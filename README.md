the day's world news in six stories: Iran striking US bases in Kuwait and

This is a round-2 entry, rebuilt from scratch with a stronger front page:
sharper headlines, tighter summaries, a numbered grid and a navy science

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3, Pillow + DejaVu fonts) renders the 1024×1024 front page
from the stories table and writes it to `/output/entry.png` (or
`$MAKEFUN_OUTPUT_DIR`). `python3 main.py --check` validates an existing output
file without rewriting it.
